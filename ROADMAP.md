# Roadmap

## Initial implementation / release hardening

- Validate the quickstart on Linux Docker hosts and complete independent security review.
- Measure calendar API latency, end-to-end event propagation, and 20 concurrent readers on documented hardware.
- Validate with warehouse operators: explainability, cancellation exceptions, real service overruns, and operational calendars.
- Complete Portuguese translations, scheduling accessibility checks, finer-grained event payloads and pagination.

## P1 - after operational feedback

- Teams, forklifts and staging-zone capacity.
- Customer-specific SLA penalties and configurable optimization policies.
- Authenticated carrier accounts, reschedule requests and email notifications.
- Cross-site dashboards and integration templates.
- Quantitative scenario comparison.

## P2 - future work

- Optional OR-Tools/CP-SAT, QR/kiosk, offline PWA and external ETA feeds.
- Advanced safety/hazmat policies, telematics and EDI.

Pilot adoption, repeat use, successful installations, integrator feedback and measured operational outcomes matter more than stars. Never claim reduced waiting without measuring an actual pilot.
